# KJ Product Kit

Personal design system for KJ apps, portfolio, dashboards and SaaS tools.

## Visual language

- Modern SaaS / developer-first
- Premium but simple
- Zinc/slate neutral base
- Amber/gold primary accent
- Teal/cyan secondary accent
- Subtle borders
- Rounded cards
- Clean typography
- Light and dark mode by default

## Agent rules

When implementing UI:

- Use KJ tokens and CSS variables.
- Use amber for primary CTAs and active states.
- Use teal for secondary highlights, links, charts and info states.
- Prefer zinc/slate surfaces.
- Prefer rounded-xl / rounded-2xl cards.
- Use subtle borders over heavy shadows.
- Keep whitespace generous.
- Avoid loud gradients except in hero sections.
- All UI should work in light and dark mode.
- Do not introduce a new UI library unless explicitly requested.
